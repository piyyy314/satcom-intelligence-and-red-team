---

## Reporting a Vulnerability

The GHOST-WATCH C2 project takes the security of satellite communication software and defensive audit tooling seriously. If you believe you have discovered a security vulnerability in this project, please report it privately:

1. **Do NOT report security vulnerabilities via public GitHub issues.**
2. Send an email with vulnerability details to: **baalbek.313@gmail.com**
3. Please include:
   - A description of the issue and affected components (e.g., Express server endpoints, Python tools, or client UI state).
   - Step-by-step reproduction instructions or a minimal proof of concept.
   - Potential impact of the vulnerability.

### Response Timeline

- **Initial Response:** Within 48 hours of receipt.
- **Status Assessment & Triage:** Within 5 business days.
- **Fix & Public Disclosure:** Coordinated with the reporter after a patch has been verified and released.

---

## Responsible Use Notice

**GHOST-WATCH C2** is designed strictly for:
- Academic research and educational demonstrations.
- Ground station defense auditing and RF telemetry monitoring within authorized testbeds.
- Hardware-in-the-loop laboratory diagnostics (e.g., ADALM-Pluto SDR).

Do not target or deploy against live operational satellite ground stations or third-party space assets without explicit authorization.
